## Inputs and provenance

Record dataset accessions, releases, filenames, hashes, citation and license.
Identify raw versus processed data and author-code version when used.

## Conventions

Record organism, assay, sample unit, axis ordering, normalization, filtering,
cell/gene selection, controls, randomness and comparison tolerance.

## Limits

State which preprocessing, analyses and biological interpretations this run
can check. Identify shared data or algorithms that prevent independence.

## Independent checks

## Blocked or uncovered claims

proposal or explicitly authorized issue link.
