## Abstract

Search public BioStudies studies and GEO Series online. Each result contains
one page of study metadata, retrieval information and a continuation cursor.
Data files are downloaded separately.

WL denotes a built-in Wolfram Language function.

## Functions

### Public Study Metadata

- `BioDatasetQuery` search BioStudies or GEO study metadata
- `Dataset` (WL) query and display structured metadata
